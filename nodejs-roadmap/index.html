🚀 就现在，1 分钟内开始

打开终端，执行👇
mkdir nodejs-backend && cd nodejs-backend
npm init -y
pnpm add express
pnpm add -D typescript @types/express ts-node-dev
npx tsc --init --target es2022 --outDir dist --rootDir src --strict
创建 src/index.ts 写 GET /health，加 dev script，npm run dev → curl，旅途开始 🎯
