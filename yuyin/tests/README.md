# 测试脚本

两个零依赖的 Node 脚本（不需要 npm install），针对「每日成语 · 易混词」模块：

```bash
cd yuyin
node tests/srs.test.js          # SM-2 引擎：13 组 / 50+ 断言
node tests/study.flow.test.js   # 端到端：路由/翻卡/评分/持久化，15 组 / 55+ 断言
```

覆盖的关键行为：

- **引擎**：间隔递推（1 → 6 → 上次×EF）、三档自评对 EF 与间隔的影响、
  EF 上下限、间隔封顶 365 天、自然日边界到期、每日新学配额、
  跨天计数重置、持久化、连续天数、7 天预测。
- **回归**：间隔几何增长溢出（曾导致 `due` 变成 `null`、卡永不再到期）、
  被污染存档的净化自愈、「累计学过」不因评「忘记」而倒退。
- **端到端**：首页入口、今日看板、会话流程、未翻面防误触、
  「忘记」词条进等待态并可跳过等待、完成态统计、词库总览与分类筛选、
  配额调整、重置、其他路由未被破坏、多天连续学习、离开页面释放定时器。

脚本用极简 DOM 桩在 Node 里执行 `js/*.js`，不依赖浏览器或 jsdom。
